# Изменения

## 1.0.0 — 2026-09-14

Первая публичная версия.

- Досье с нумерованными фактами и разделом «чего в материале нет».
- Обязательный скептик с мандатом атаковать выводы оркестратора и реестр ограничений.
- Маркировка утверждений [Ф]/[Д]/[В]/[Г], раздел «где я могу ошибаться», протокол источников.
- Классификация разногласий, вердикт по каждому возражению скептика, фильтр «какое решение изменится».
- Многотактный режим с реестром ограничений и объективным критерием остановки.
- Локальный файл уроков между разборами.
